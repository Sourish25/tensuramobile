# TENSURA GRIND-RPG — SOURCE DESIGN BIBLE
Distilled from all 22 LN volumes. Terms follow the official translation.

## 1. WORLD SYSTEM FRAMING
- Skills are granted/announced by **World Language** announcements: *"Confirmed. Resist Heat…successfully acquired."*, *"Skill 'Water Blade' acquired"*, *"Combining and upgrading to extra skill 'Control Water'"*. Perfect diegetic UI.
- Great Sage diction: `Received. / Understood. / Question. / Report.` + Yes/No prompts (*Use unique skill "Predator"? Yes/No*).
- Appraisal outputs stat cards; failure states: *"Cannot analyze"*, *"Maximum limit not calculable"* (reserved for god-tier).
- The Ultimate Skill layer is Veldanava's abandoned admin system → justifies menus/system UI in-world.

## 4. SKILL SYSTEM
### Tiers
Intrinsic (racial) → Common → Extra → Unique → Ultimate (+ Manas = sentient ultimate).
- **Only an ultimate counters an ultimate.** Lower skills are canceled against them.
- Replications/copies capped at Unique.
- Ultimates can be sacrificed to negate one attack then restored from backup.
- Virtue/sin pairing: Michael–Satanael(Milim), Raphael–Belzebuth(Rimuru), Sariel–Belphegor, Metatron–Asmodeus(Luminus), Raguel–Mammon(Yuuki), Gabriel–Leviathan(Velzard), Uriel–Lucifer(Guy). Demonic skills are will-made imitations of angelic ones and immune to angelic Dominion.

### STARTER KIT (slime start)
- Slime intrinsics: **Absorb, Dissolve, Self-Regeneration**. No need to eat/sleep/breathe.
- **Great Sage (Unique):** Hasten Thought ×1000, Analyze and Assess, Parallel Operation, Cast Cancel, All of Creation (known concepts only). Provides automap, probability reports, auto-battle mode.
- **Predator (Unique), 5 subskills:** Predation (absorb target; reduced success if conscious), Analysis (research absorbed targets → copy items, learn skills/spells), Stomach (timeless storage inventory), Mimicry (copy absorbed forms/skills; mimic damage doesn't touch real body; ~3min switch cooldown; mimics evolve when source species evolves), Isolate (neutralize unanalyzable harm into magic energy).
- Predator + Ravenous → Glutton (adds Rot, Receive, Provide: give/take skills with soul-linked subordinates).
- Awakened: Great Sage → **Raphael, Lord of Wisdom** (+Mind Accelerate, Parallel Computation, Ability Adjust, Combine/Disassemble); Predator → **Belzebuth, Lord of Gluttony** (+Soul Consume, Food Chain); later merged into **Azathoth, God of the Void** (Void Collapse, Complex Space) + Shub-Niggurath.

## 5. MAGIC & COMBAT MECHANICS BANK
- **Aspectual magic** manipulates physics via magicules. Barriers block magicule flow → spells fail inside; counterplay = physical-only attacks (Megiddo: refracted sunlight bolts).
- **Holy magic runs on spiritual particles**, pierces all barriers; Disintegration = heat-seeking unblockable long cast; Melt Slash = Disintegration in blade + supersonic rush (cost Rimuru >70% MP once); Trinity Disintegration = unresistable finisher protected during cast. Holy Field purifies internal magicules over time.
- Resist tiers: Resist → Cancel/Nullify. Multilayer Barrier. Absolute Defense (Uriel) blocks Disintegration.
- Regeneration ladder: Self → Ultraspeed → Infinite. Survivor heals body but spiritual damage bypasses.
- Soul combat: Soul Consume requires breaking heart/will first; Merciless harvests souls of those who beg/lose will; Insta-Kill threads slice spiritual bodies; Dead End Rainbow destroys astral body; Death Streak 99.999%-lethal soul-targeted black sphere.
- Domains/world-type skills: Fantastical World, World of Dead/Destruction/Temptation, Determiner arena-space (drags weaker foes into caster-favored arena), Zarario's spatial defense field.
- Utility mechanics bank: Time Stop (rare immunity), Gravity Collapse cell, space-time freeze banning teleport (Dominate Space), probability edit (Control Probability, Alter Destiny 1/day), conditional auto-death curse (Dream End), heart-core destruction→forced servitude, labyrinth-bound respawn, Separate Body bait tactics, once-per-day nukes (Judgment Bullet), possession/override charm cured via administrator rights, corpse-absorption regen countered by Full Isolation Barrier, Castle Guard loyalty-economy defense, Anti-Skill cancels everything but loses to raw overwhelming force.
- Awakening multiplier scales with base EP (~4× Carillon, ~5× Frey, 10× Rimuru). Awakening needs demon-lord-seed + soul corridor + souls.
- Naming drains namer's magicules (life force); named monster species-jumps. Throughput canon: ~5 sec/name, 150,000 orcs in 10 days.
- EP ≠ win rate. Output vs stats are separate axes.

## 11. GODHOOD PATH (ENDGAME DESIGN)
Veldanava created world spending Void Collapse (his inexhaustible source) → weakened → died to mere humans. Built Ultimate Skill system as world-admin tools.
Rimuru's route: (1) Analyze-and-Assess an administrator ultimate (Michael) → seize it → inherit Ultimate Dominion; (2) merge ultimates into Azathoth containing Void Collapse in Complex Space ("could rebuild the world thousands of times… still wasn't full"); (3) survive End of Space-Time (zero time flow); unlock Time Warp (soul-corridor partners as anchor coordinates); gain Argos monitoring omniscience. Ciel (Manas) can recreate entire worlds including memories.
Post-god hooks: seed/recreate worlds at End of Space-Time, Celestial Palace gates to countless worlds, collect 7 Genesis relics, train successors eternally in expanding labyrinth, Magus mech-suit research, Thalion rebuild.
Hard rules to codify: naming=magicule burn; soul corridor (energy lending, comms in stopped time, shared power, warp anchors); resurrection tiers (labyrinth unlimited/Ramiris; Asmodeus allies; Metis raise-dead; only full spiritual life-forms self-resurrect); time layers (labyrinth-local twist, Time Stop, Dimensional Leap needs stored coords+fuel); EP≠winrate; Genesis gear scales with owner into tens of millions.
